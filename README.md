# Eagle Commander — releases

Downloads, the update feed and the website of
[Eagle Commander](https://eaglecommander.eaglesoft.si), a two-panel file
manager for macOS in the tradition of Total Commander.

- **Download:** <https://eaglecommander.eaglesoft.si>, or the
  [latest release](https://github.com/ulebule/eagle-commander-releases/releases/latest).
- **Homebrew:** `brew install --cask ulebule/tap/eagle-commander`

This repository holds no source code. Everything in it is published from the
app's own repository by its release scripts; changes made here by hand are
overwritten by the next release.
