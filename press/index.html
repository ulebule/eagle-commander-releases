In one sentence

Eagle Commander is a two-panel file manager for macOS in the tradition of Total Commander, made in Slovenia by one developer.

In a paragraph

Eagle Commander brings the keyboard-driven, two-panel way of working that Total Commander made popular on Windows to the Mac. Copy with F5, move with F6, mark files with the space bar, open archives like folders, compare and synchronize folders, rename hundreds of files with a preview, and connect to servers over SFTP, FTPS and FTP — all without reaching for the mouse. It speaks six languages, costs €9.99 once and can be tried for 30 days.

The longer story

Many people who move from Windows to the Mac miss Total Commander, the two-panel file manager they have used for years, often decades. Finder is built for a different way of working. Eagle Commander was written for them, as a native Mac app.

It keeps the habits that make a two-panel file manager fast. Two panels with tabs, side by side; the F-keys along the bottom; files marked red with the space bar; the command line under the panels. An archive opens like a folder, a server over SFTP, FTPS or FTP behaves like a disk, and the branch view lists every file below a folder in one flat list, where every command works on them.

Around that it has what people do with files every day: copying and moving with a queue that can be paused, multi-rename with patterns and regular expressions that can be taken back, folder comparison and synchronization, file comparison line by line, search by name, size, date and content, a duplicate finder, checksums, a viewer for text, hex and images, and quick view of the file under the cursor in the other panel.

Eagle Commander sends nothing anywhere: no telemetry, no usage counts, no crash reports. The licence key is checked on the Mac, without the internet.
